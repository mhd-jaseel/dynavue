# DYNAVUE

Professional MERN Stack Photography Platform.

## Project Structure

- `client/`: React frontend (Vite)
- `server/`: Express backend (Node.js)

## Getting Started

1. Install dependencies for both client and server:
   ```bash
   npm run install-all
   ```

2. Run the development environment:
   ```bash
   npm run dev
   ```
   This will start both the client (on port 5173) and the server (on port 5000) concurrently.

## Tech Stack
- **Frontend**: React, TailwindCSS, Framer Motion
- **Backend**: Node.js, Express, MongoDB, Socket.io
- **Services**: Cloudinary (Media), Firebase (Push Notifications)
